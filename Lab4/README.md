# Лабораторная работа №4. Изучение корреляционных свойств последовательностей синхронизации

## Описание задания
Исследование алгоритмов формирования псевдослучайных двоичных последовательностей на основе линейных регистров сдвига с обратной связью, расчет периодической автокорреляционной и взаимнокорреляционной функций, применяемых для кадровой и временной синхронизации приемников и передатчиков в сетях мобильной связи, а также проверка свойств псевдослучайности.

## Что сделано
1. **Генерация кодов Голда (C++):** по схеме для нечетной группы (вариант 26: $x_1 = 26 = 11010_2$, $y_1 = 1 = 00001_2$) сформирована псевдослучайная последовательность Голда периода $N = 2^5 - 1 = 31$.
2. **Таблица автокорреляции:** реализован циклический сдвиг и рассчитана периодическая АКФ для всех задержек $\tau \in [0; 31]$ по формуле совпадений и несовпадений бит $R(\tau) = \frac{M(\tau) - D(\tau)}{N}$.
3. **Вторая последовательность и ВКФ:** сформирована последовательность со смещенными начальными состояниями ($x_2 = 27 = 11011_2$, $y_2 = 28 = 11100_2$), вычислена взаимная корреляция при нулевом сдвиге ($R_{12} = \frac{14 - 17}{31} \approx -0{,}10$).
4. **Моделирование в MATLAB:** повторен расчет АКФ и ВКФ. Проанализированы особенности встроенной функции `xcorr()`: на битах $\{0, 1\}$ она вычисляет число совпавших единиц (8), а при приведении к биполярному представлению $\{+1, -1\}$ с нормализацией дает точное значение $-0{,}0968 \approx -0{,}10$.
5. **Анализ и график АКФ:** построен сравнительный график ручного циклического расчета и функции `autocorr()`.
6. **Дополнительное задание:** реализована функция `is_m_sequence()` для проверки трех постулатов Голомба (сбалансированность, цикличность, корреляция).

## Структура файлов
* `main.cpp` - программа на C++: генерация кодов Голда, формирование таблицы АКФ, расчет ВКФ и валидация критериев M-последовательности.
* `main.m` - скрипт MATLAB: генерация кодов Голда, вычисление корреляций, сравнение со встроенными функциями `xcorr`/`autocorr` и построение графиков.
