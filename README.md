# Основы систем мобильной связи (ОСМС)

Репозиторий содержит лабораторные работы и отчеты по курсу «Основы систем мобильной связи» (СибГУТИ, каф. ТС и ВС, группа ИКС-433).

## Структура репозитория

* [**Lab1/**](./Lab1/) — Лабораторная работа №1: «Цифровая обработка речевых сигналов» (дискретизация, квантование, спектральный анализ, pitch shift).
* [**lab2/**](./Lab2/) — Лабораторная работа №2: «Проектирование радиопокрытия мобильных сетей» (бюджеты каналов UL/DL, модели потерь FSPM, COST 231 Hata, UMiNLOS, расчет числа сайтов).
* [**lab4/**](./Lab4/) — Лабораторная работа №4: «Изучение корреляционных свойств псевдослучайных последовательностей» (генератор кодов Голда на C++ и MATLAB, автокорреляция, взаимная корреляция, проверка критериев М-последовательности).

## Стек технологий

* **Языки и среды:** MATLAB, C++
