# Лабораторная работа №1. Цифровая обработка речевых сигналов

## Описание задания
Исследование базовых процессов цифровой обработки звука: аналого-цифрового преобразования, дискретизации во времени, квантования по уровню и модификации спектра речевых сигналов.

## Что сделано
1. **Анализ исходного сигнала:** записан речевой файл `voice.wav`, построены осциллограмма, амплитудный спектр и спектрограмма.
2. **Дискретизация и алиасинг:** промоделировано понижение частоты дискретизации до 720 Гц и 180 Гц. Продемонстрирован эффект наложения спектров (алиасинг) при нарушении теоремы Котельникова–Найквиста.
3. **Квантование:** реализовано квантование с разной разрядностью, оценены ошибки квантования и отношение сигнал/шум квантования.
4. **Дополнительное задание:** реализовано повышение тона голоса.

## Структура файлов
* `main_task.m` — скрипт основного задания (дискретизация, квантование, построение спектров).
* `additional.m` — скрипт дополнительного задания (алгоритмы pitch shift).
* `voice.wav` — исходный речевой сигнал.
